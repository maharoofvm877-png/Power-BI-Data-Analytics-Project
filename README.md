Birth Analysis Dashboard | Power BI

Project Overview

The Birth Analysis Dashboard is an interactive data visualization project developed using Microsoft Power BI. It focuses on analyzing birth-related data and identifying patterns in birth outcomes, birth weight, maternal age, pregnancy duration, parental visits, and other important factors.

The dashboard provides meaningful insights through interactive charts, KPI cards, and slicers to support better understanding of birth-related trends.

 Project Objectives

- Analyze total births and birth-related trends.
- Understand the relationship between maternal age and birth weight.
- Analyze birth outcomes and premature births.
- Compare birth statistics based on gender.
- Explore the impact of maternal habits on birth outcomes.
- Examine parental and doctor visits.
- Identify patterns in pregnancy duration and birth weight.

 Dashboard Features

Page 1 – Birth Overview Dashboard

- Total Births
- Average Birth Weight
- Average Mother Age
- Average Pregnancy Weeks
- Birth Distribution by Gender
- Premature Birth Analysis
- Births by Mother's Age Group
- Average Birth Weight by Gender
- Births by Maternal Habits

Page 2 – Birth Outcome Dashboard

- Average Parental Visits
- Average Doctor Visits
- Average Weight Gained
- Average Father's Age
- Low Birth Weight Percentage
- Average Birth Weight by Mother's Age Group
- Birth Distribution by Marital Status
- Average Pregnancy Weeks by Gender
- Birth Weight by Maternal Habits and Gender
